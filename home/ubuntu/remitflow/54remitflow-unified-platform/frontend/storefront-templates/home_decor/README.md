# HomeStyle Decor - Storefront Template

Home decor template with room planner, style guide, and interior design consultation

## Quick Start

```bash
# Deploy this template
./deploy_template.sh home_decor
```

## Features

- Room Planner
- Style Guide
- Design Consultation
- Custom Orders
- Ar Preview

## Categories

- Furniture
- Lighting
- Textiles
- Wall Art
- Kitchen & Dining
- Outdoor

## Theme Colors

- Primary: #0f766e
- Secondary: #f59e0b
- Accent: #1f2937

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
