# Glow Beauty Store - Storefront Template

Beauty store template with skin analysis, product recommendations, and beauty tips

## Quick Start

```bash
# Deploy this template
./deploy_template.sh beauty
```

## Features

- Skin Analysis
- Product Recommendations
- Beauty Tips
- Virtual Makeup
- Subscription Boxes

## Categories

- Skincare
- Makeup
- Haircare
- Fragrances
- Tools & Brushes
- Men's Grooming

## Theme Colors

- Primary: #ec4899
- Secondary: #a855f7
- Accent: #fbbf24

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
