# Afro Chic Boutique - Storefront Template

Fashion boutique template with virtual try-on, style quiz, and size guide

## Quick Start

```bash
# Deploy this template
./deploy_template.sh fashion
```

## Features

- Virtual Tryon
- Style Quiz
- Size Guide
- Gift Wrapping
- Personal Stylist

## Categories

- Dresses
- Tops
- Skirts
- Ankara Sets
- Accessories
- Jewelry
- Bags
- Shoes

## Theme Colors

- Primary: #dc2626
- Secondary: #f59e0b
- Accent: #000000

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
