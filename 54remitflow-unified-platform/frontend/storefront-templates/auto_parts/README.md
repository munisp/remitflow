# AutoPro Parts - Storefront Template

Auto parts template with VIN lookup, compatibility checker, and installation guides

## Quick Start

```bash
# Deploy this template
./deploy_template.sh auto_parts
```

## Features

- Vin Lookup
- Compatibility Checker
- Installation Guides
- Mechanic Finder
- Bulk Orders

## Categories

- Engine Parts
- Brakes
- Suspension
- Electrical
- Body Parts
- Accessories

## Theme Colors

- Primary: #1e293b
- Secondary: #f97316
- Accent: #dc2626

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
