# Mama's Kitchen - Storefront Template

Restaurant template with menu builder, table reservations, and meal subscriptions

## Quick Start

```bash
# Deploy this template
./deploy_template.sh restaurant
```

## Features

- Table Reservations
- Meal Subscriptions
- Dietary Filters
- Calorie Counter
- Chef Specials

## Categories

- Main Dishes
- Soups
- Sides
- Drinks
- Desserts
- Breakfast
- Lunch Specials

## Theme Colors

- Primary: #dc2626
- Secondary: #f59e0b
- Accent: #fbbf24

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
