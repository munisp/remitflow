# TechHub Store - Storefront Template

Electronics store template with product comparison, installment plans, and warranty management

## Quick Start

```bash
# Deploy this template
./deploy_template.sh electronics
```

## Features

- Installments
- Trade In
- Warranty
- Product Comparison
- Tech Support

## Categories

- Smartphones
- Laptops
- Tablets
- Accessories
- Smart Home
- Gaming
- Audio
- Cameras

## Theme Colors

- Primary: #1e40af
- Secondary: #06b6d4
- Accent: #3b82f6

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
