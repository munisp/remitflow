# FitZone Sports - Storefront Template

Sports store template with size finders, workout plans, and fitness tracking

## Quick Start

```bash
# Deploy this template
./deploy_template.sh sports
```

## Features

- Size Finder
- Workout Plans
- Fitness Tracking
- Team Orders
- Product Reviews

## Categories

- Footwear
- Apparel
- Equipment
- Accessories
- Supplements
- Outdoor Gear

## Theme Colors

- Primary: #0891b2
- Secondary: #f97316
- Accent: #1f2937

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
