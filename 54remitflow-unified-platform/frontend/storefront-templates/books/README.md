# BookWorm Store - Storefront Template

Bookstore template with reading lists, book clubs, and author events

## Quick Start

```bash
# Deploy this template
./deploy_template.sh books
```

## Features

- Reading Lists
- Book Clubs
- Author Events
- Book Recommendations
- Ebook Downloads

## Categories

- Fiction
- Non-Fiction
- Children's Books
- African Literature
- Educational
- Comics & Manga

## Theme Colors

- Primary: #7c3aed
- Secondary: #f59e0b
- Accent: #1f2937

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
