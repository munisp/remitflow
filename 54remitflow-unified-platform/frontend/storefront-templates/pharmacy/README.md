# HealthPlus Pharmacy - Storefront Template

Pharmacy template with prescription upload, medication reminders, and health tips

## Quick Start

```bash
# Deploy this template
./deploy_template.sh pharmacy
```

## Features

- Prescription Upload
- Medication Reminders
- Health Tips
- Pharmacist Chat
- Insurance Claims

## Categories

- Prescription Drugs
- OTC Medications
- Vitamins & Supplements
- Personal Care
- Medical Devices
- Baby Care

## Theme Colors

- Primary: #0ea5e9
- Secondary: #10b981
- Accent: #ffffff

## Sample Products

2 sample products included

## Customization

Edit `config.json` to customize:
- Store name and tagline
- Theme colors
- Categories
- Features
- Payment methods
