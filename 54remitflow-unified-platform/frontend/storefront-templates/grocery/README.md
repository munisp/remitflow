# Fresh Market - Storefront Template

Grocery store template with subscription boxes, recipe suggestions, and same-day delivery

## Quick Start

```bash
# Deploy this template
./deploy_template.sh grocery
```

## Features

- Same Day Delivery
- Subscription Boxes
- Recipe Suggestions
- Bulk Ordering
- Fresh Guarantee

## Categories

- Fresh Produce
- Meat & Poultry
- Dairy & Eggs
- Bakery
- Pantry
- Beverages
- Household

## Theme Colors

- Primary: #10b981
- Secondary: #f97316
- Accent: #fbbf24

Edit `config.json` to customize:

- Theme colors
