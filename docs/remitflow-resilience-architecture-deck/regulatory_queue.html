Regulatory filing becomes a durable workflow
CTR and SAR delivery is no longer a direct provider call. Every filing has a tenant scope, durable state, recovery path, and forensic event history.
01 / ENQUEUE

Tenant-scoped filing

Compliance procedures create a PostgreSQL queue record before external delivery is attempted.

→
02 / CLAIM

Atomic worker lease

`SKIP LOCKED` claiming prevents two workers from submitting the same filing concurrently.

→
03 / SUBMIT

Configured regulator path

The worker invokes the jurisdiction provider with bounded timeout and explicit result handling.

→
04 / RECOVER

Retry or dead letter

Exponential backoff persists retry intent; exhausted work transitions to reviewable dead letter.

→
05 / GOVERN

Admin requeue

Only an administrator can requeue a failed filing, with actor identity written to the audit chain.

OPERATING EVIDENCE
Prometheus reports queued, submitted, retry, and dead-letter outcomes; alerts surface a dead letter, backlog, or stalled worker before a compliance deadline is missed.
