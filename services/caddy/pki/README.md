# RemitFlow Caddy PKI Certificates

This directory contains PKI certificates used by Caddy for mTLS and internal CA validation.

## Files Required

| File | Purpose | How to Generate |
|---|---|---|
| `b2b-partner-ca.pem` | CA certificate for B2B partner mTLS | Provided by B2B partners or your internal CA |
| `internal-ca.pem` | Internal CA for Prometheus/metrics mTLS | Generated by your internal PKI |

## Generating a Self-Signed Internal CA (for development)

```bash
# Generate internal CA key and certificate
openssl genrsa -out internal-ca.key 4096
openssl req -new -x509 -days 3650 -key internal-ca.key \
  -out internal-ca.pem \
  -subj "/C=US/O=RemitFlow/CN=RemitFlow Internal CA"

# Generate B2B partner CA (for testing)
openssl genrsa -out b2b-partner-ca.key 4096
openssl req -new -x509 -days 3650 -key b2b-partner-ca.key \
  -out b2b-partner-ca.pem \
  -subj "/C=US/O=RemitFlow/CN=RemitFlow B2B Partner CA"
```

## Production

In production, mount these as Kubernetes Secrets:

```bash
kubectl create secret generic caddy-pki \
  --from-file=b2b-partner-ca.pem=./b2b-partner-ca.pem \
  --from-file=internal-ca.pem=./internal-ca.pem \
  -n remitflow
```

Or as Docker Secrets:

```yaml
secrets:
  b2b_partner_ca:
    file: ./secrets/b2b-partner-ca.pem
  internal_ca:
    file: ./secrets/internal-ca.pem
```

**Never commit actual certificate files or private keys to this repository.**
